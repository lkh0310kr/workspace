# Welcome to your Vault

This vault is a folder of plain **Markdown** files. The app reads them directly from disk, so your notes stay *yours*: no database or proprietary format is involved.

- Browse folders in the sidebar
- Tap a note to read it
- Pull down to rescan the vault after adding files

Try the links: [[Markdown Showcase]], [[project|the sample project]], or a relative link to [today's journal](Journal/2026-09-29.md).

> Files live in `Application Support/vault`. A future version will sync this folder with GitHub.
