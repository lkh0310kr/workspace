# Interaction coordinator

App scope 구현 기준은 [Desktop interaction](../../apps/workspace-app/docs/interaction/README.md)이다. 표시/입력 결정표, overlay와 portal 수명, workspace/chip 전이와 focus 책임을 정의한다.

Guest 생성·재부착은 [Browser lifecycle](../../apps/workspace-app/docs/browser/lifecycle.md), shell 상태는 [layout](../../apps/workspace-app/docs/layout/README.md)이 소유한다.
