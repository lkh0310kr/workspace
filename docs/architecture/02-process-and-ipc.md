# 프로세스와 IPC

App scope 기준은 [Desktop IPC 지도](../../apps/workspace-app/docs/ipc/README.md)와 [시작·종료](../../apps/workspace-app/docs/runtime/README.md)다. Main/preload/renderer API, content/system/terminal/browser/PKMS family와 상태 변환은 해당 문서에서 관리한다.

여러 제품의 서비스 경계는 [전체 context](./01-overview.md), native 자격 증명·로컬 데이터 수명은 [Desktop persistence](../../apps/workspace-app/docs/persistence/README.md)를 따른다.
