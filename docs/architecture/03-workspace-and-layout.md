# Workspace와 layout

App scope 구현 기준은 [Workspace Desktop layout](../../apps/workspace-app/docs/layout/README.md)이다. model·pane config·activation·persist·preview·drag·dirty close 계약을 해당 문서에서 관리한다.

전역 제품 경계는 [시스템 context](./01-overview.md), guest 표시·focus는 [Interaction](../../apps/workspace-app/docs/interaction/README.md), 저장·복구는 Desktop 문서 색인을 따른다.
