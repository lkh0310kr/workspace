# 프로젝트 정의

Workspace는 사용자가 선택한 로컬 폴더에서 문서와 코드를 편집하고, 같은 작업 공간에서 Home, Terminal, Browser를 사용하는 데스크톱 작업 공간이다. 파일은 로컬 파일 시스템에 직접 저장한다. 동기화가 필요하면 사용자가 별도로 설치한 동기화 앱이 관리하는 로컬 폴더를 연다.

## 제품 경계

| 영역 | 책임 | 기준 |
| --- | --- | --- |
| Desktop | 로컬 폴더와 파일 접근, 기능 조립, Electron·운영체제 host | [`apps/desktop`](../../apps/desktop/README.md) |
| Editor | 로컬 파일 편집 UI, 트리·검색·공통 파일 뷰어 계약 | [`packages/editor`](../../packages/editor/README.md) |
| Home | Home 화면과 시스템 요약 UI | [`packages/home`](../../packages/home/README.md) |
| Browser | 브라우저 pane UI와 host 계약 | [`packages/browser`](../../packages/browser/README.md) |
| Terminal | 터미널 pane UI·입력·검색·터미널 도메인 | [`packages/terminal`](../../packages/terminal/README.md) |
| UI | 기능 패키지가 함께 쓰는 UI primitive와 스타일 | [`packages/ui`](../../packages/ui/README.md) |
| Server | 배포 상태용 `GET /api/health`; Desktop 편집과 독립 | [`apps/server`](../../apps/server/README.md) |

Desktop이 로컬 파일 접근 권한과 저장을 소유한다. 기능 패키지는 Electron Main, preload, 운영체제 API에 직접 접근하지 않고 필요한 능력을 host 계약으로 받는다. Server는 사용자 계정이나 자격 증명을 관리하지 않는다.

## 제품 우선순위

현재 우선순위는 Desktop의 로컬 편집 경험과 Home·Terminal·Browser의 기존 동작을 유지하면서 기능 경계를 정리하는 것이다. 앱 내부 계정, 클라우드 파일 동기화, 공동 편집, 별도 웹·모바일 앱은 현재 활성 범위에서 제외한다. 보류 자료는 `archive/`에 보존한다.

## 사용자 여정

| ID | 여정 | 기대 결과 | 소유 영역 |
| --- | --- | --- | --- |
| J-01 | 로컬 폴더를 열고 파일 탐색 | 선택한 폴더의 파일과 하위 디렉터리를 확인하고 파일을 연다. | Desktop, Editor |
| J-02 | Markdown·코드 파일 편집 | 변경 내용을 선택한 로컬 경로에 저장하고 다시 열어 확인한다. | Desktop, Editor |
| J-03 | Home·Terminal·Browser 사용 | 기존 pane 동작과 작업 상태를 유지하며 각 기능을 사용한다. | Desktop 및 해당 기능 패키지 |
| J-04 | 배포 상태 확인 | `GET /api/health`가 Worker 상태를 반환한다. | Server |

파일 동기화는 Editor 기능이 아니다. 외부 동기화 도구가 로컬 동기화 상태와 충돌을 관리한다.
