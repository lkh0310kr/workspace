# 프로젝트 정의

Workspace는 사용자가 선택한 로컬 폴더에서 문서와 코드를 편집하고, 터미널·브라우저·파일 뷰어를 함께 사용하는 데스크톱 작업 공간이다. 문서는 파일 시스템에 직접 저장한다. 클라우드 동기화가 필요하면 사용자가 운영체제에 설치한 동기화 앱이 관리하는 로컬 폴더를 연다.

## 제품 경계

| 영역 | 책임 | 기준 |
| --- | --- | --- |
| Desktop | 로컬 폴더, Editor, 터미널, 브라우저, 파일 확인과 시스템 정보 | [`apps/desktop`](../../apps/desktop/README.md) |
| Server | 별도 설정된 identity issuer로 인증하는 Workspace 서비스 API | [`apps/server`](../../apps/server/README.md) |
| Editor package | 제품 shell이 provider를 연결해 사용하는 편집기와 트리 UI | [`packages/editor`](../../packages/editor/README.md) |

Desktop은 파일 접근 권한과 로컬 저장을 소유한다. Server는 별도 서비스 자격 증명을 암호화해 보관하며, Desktop 로컬 Editor의 저장 경로에 개입하지 않는다.

## 제품 우선순위

현재 개발은 Desktop 로컬 편집 경험과 이를 지원하는 Server에 집중한다. 계정·공동 편집·앱 내부 클라우드 동기화는 활성 제품 범위가 아니다. 기존 구현 자료는 저장소의 archive에 보존한다.

## 사용자 여정

| ID | 여정 | 기대 결과 | 소유 영역 |
| --- | --- | --- | --- |
| J-01 | 로컬 폴더를 열고 파일 탐색 | 선택한 폴더의 파일과 하위 디렉터리를 탐색한다. | Desktop |
| J-02 | Markdown·코드 파일을 편집 | 변경 내용을 선택한 로컬 경로에 저장하고 다시 열어 확인한다. | Desktop, Editor |
| J-03 | 시스템 정보 확인 | 현재 기기의 요약 정보를 표시한다. | Desktop |
| J-04 | 서버 제공자 연결 관리 | 설정된 identity issuer로 인증한 요청만 서비스 자격 증명에 접근한다. | Server |

파일 동기화는 Editor 기능이 아니다. Google Drive 데스크톱 앱에서 로컬 동기화 상태와 충돌을 관리한다.
