# 플랫폼 우선순위와 작업 범위

현재 제품 작업은 App과 Web 플랫폼에 집중한다. PKMS iOS 프로젝트는 당분간 중단하며, 재개 결정 전까지 정기적인 개발·문서화·검증 범위에 포함하지 않는다.

## 현재 우선순위

- **App**: Workspace Desktop 및 관련 앱 경계
- **Web**: PKMS Web과 이를 지원하는 서버 기능
- **중단**: PKMS iOS

`apps/pkms-ios/`와 iOS 전용 구현·테스트·문서는 사용자가 별도 재개를 요청하기 전까지 에이전트의 일반적인 읽기, 분석, 수정 대상에서 제외한다. 다른 플랫폼 작업 중 해당 경로를 탐색하거나 계약 근거로 참조하지 않는다. 저장소의 전역 문서에 이미 있는 제품 범위 표기는 현재 작업 허가로 해석하지 않는다.

`apps/pkms-ios/legacy/`도 같은 제외 범위에 속한다. 요청에 따라 디렉터리 구조만 제한적으로 확인한 결과, `legacy/v1/`은 별도 Xcode 프로젝트로 남아 있는 이전 PKMS iOS 앱 구현이다. SwiftUI 앱 소스와 Markdown 편집, Map, GitHub 기반 Vault sync, Agent runtime, 테스트와 SampleVault가 포함되어 있다. 함수 동작이나 구현 품질은 조사하지 않았다. 이 한 번의 식별 이후에는 `pkms-ios` 전체를 일반적인 읽기·분석·수정 대상에서 제외한다.

## Android Data Node 아카이브

Android Data Node는 현재 선택한 App/Web 우선순위에 포함하지 않는다. 관련 구현과 연구 자료는 현재 제품 경로에서 분리해 최상위 `archive/` 아래에 보존한다. 파일 목록과 이동 이유는 [Android Data Node 아카이브 기록](../archive/android-data-node.md)에 정리했다. 아카이브 이후 새 작업에서 사용자가 명시적으로 재개하지 않는 한 구현·조사 대상으로 다시 포함하지 않는다.

## 정책 변경

이 우선순위 변경은 [제품 범위와 핵심 여정](./프로젝트%20정의.md)의 활성 작업 범위를 보충한다. PKMS iOS 재개는 별도 사용자 결정으로 기록한 뒤 이 문서와 해당 작업 범위를 갱신한다.
