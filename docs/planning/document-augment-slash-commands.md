# 문서 증강 + 슬래시 커맨드

**상태:** 구현 중 (2026-09-02)  
**관련:** [japanese-study-assist.md](./japanese-study-assist.md) (Study Assist 전체)

## 상황

일본어 학습 노트를 쓰다 보면 빠진 개념 설명, 예문, 할 일, 복습 포인트를 같은 형식으로 채워 넣고 싶다. 선택 기반 Study 채팅은 “이 한 줄”에 맞지만, **문서 전체 맥락**에서 무엇을 더 쓸지는 별도 흐름이 필요하다.

## 행동

1. Markdown 노트 에디터에서 커서 위치에 `/` 입력
2. Notion식 popover에서 **ai › 증강** 선택 (또는 `/ai`, `/증강` 필터)
3. **추가 지시 없이** LLM이 현재 파일 전체를 읽고 보강할 내용 추론
4. 에디터 **하단 미리보기**에서 결과 확인
5. **삽입** → 슬래시 커맨드 텍스트 제거 후 커서 위치에 삽입 / **취소** → 무변경

## 성공 기준

- 30초 안에 “노트에 한 블록 더 쓸 내용”을 확인하고 넣거나 버릴 수 있다
- 생성물이 기존 노트의 마크다운 스타일(제목, 할 일, 인용, wikilink 등)을 따른다
- Accept 전에는 본문이 바뀌지 않는다

## 비목표 (v1)

- 사용자 추가 프롬프트 입력
- 미리보기 없이 즉시 삽입

- 전체 문서 덮어쓰기 / diff 뷰
