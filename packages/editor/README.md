# Shared Editor package

이 패키지는 Desktop Editor가 사용하는 공통 Tree pane/frame·row·문서 tab·CodeMirror text/Markdown UI와 provider 계약을 제공한다. Quick Open과 Find in Files UI·검색 lifecycle도 소유한다. 파일 종류와 viewer 형식 정책, 파일 viewer UI·상태·자원 수명은 `@workspace/editor/assets`와 `@workspace/editor/viewers`에서 제공한다. Desktop은 `EditorViewerHost`로 파일 접근, media URL, native picker와 Desktop 전용 EPUB·CAD·3D renderer를 연결한다. Electron, 인증, 동기화, 로컬 파일시스템 구현은 소유하지 않는다. Tree provider 상태와 작업 실행은 host가 담당하고, pane의 header/content/footer 조립과 row presentation은 공유 API를 사용한다. Editor tree의 확장·scroll 상태, sidebar 표시 설정, tree shortcut·keyboard 정책도 이 package가 소유하며 Desktop host가 pane identity와 로컬 파일 provider를 연결한다.

[구현 스펙과 읽는 순서](../../docs/architecture/editor/README.md) → [provider](../../docs/architecture/editor/provider.md) → [text surface](../../docs/architecture/editor/code/README.md) → tree/Markdown/search 순으로 읽는다. `EditorMarkdownEditor`는 공통 문서 surface 조립 entrypoint이고, `EditorTreePane`은 tree row를 조립하는 public entrypoint다. Host별 저장·파일 동작은 [루트 docs](../../docs/README.md)에서 해당 기능 문서를 찾는다.

공개 entrypoint와 CSS subpath(`editor-pane-chrome.css`, viewer styles 포함)는 [package.json](./package.json), export symbol은 [index.ts](./src/index.ts)를 기준으로 한다. Find in Files package API는 `@workspace/editor/search`에서 `EditorProvider`와 pane callback을 받으며 Desktop local provider lease는 host가 관리한다. Tree toolbar는 `EditorTreeToolbar`를 사용하고 저수준 row와 virtual-list는 package 안에 둔다. `npm run check:editor-tree-contract`가 공용 tree 진입점과 비공개 구현 사용을 검사한다. [공개 API 분류와 UI](../../docs/architecture/editor/public-api.md)에서 API별 owner를 확인한다.
