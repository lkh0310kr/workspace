# PKMS iOS legacy 아카이브 기록

작성일: 2026-11-16
상태: 아카이브됨

사용자 결정에 따라 `apps/pkms-ios/legacy/`의 추적 파일 120개를 `archive/apps/pkms-ios/legacy/`로 이동했다. `legacy/v1/`은 별도 Xcode 프로젝트로 보존돼 있던 이전 PKMS iOS 앱이다. 구조상 SwiftUI 앱, Markdown·Map 기능, GitHub Vault 동기화, Agent runtime, 테스트 및 SampleVault를 포함한다.

이동은 보존 목적이며, 내부 동작·구현 품질·재현 가능성은 검토하지 않았다. 현재 PKMS iOS 작업은 중단 상태이며, 사용자가 재개를 요청하기 전까지 `apps/pkms-ios/`의 나머지 영역도 일반적인 읽기·분석·수정 대상에서 제외한다. 이 아카이브 기록과 이동된 legacy 경로는 해당 제외 정책의 예외적 지속 작업이 아니다.
